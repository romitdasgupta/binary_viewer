About BinaryStudio

A tool for looking inside executables and libraries, and for learning how they work.

BinaryStudio opens Mach-O (thin and universal), ELF (32- and 64-bit) and PE (PE32 and PE32+) files and shows them as decoded structures beside the raw bytes. It covers headers, load commands, segments and sections, symbols, imports and exports, relocations and fixups, code signatures, and disassembly. You can move between file offsets, virtual addresses and the hex view.

The Learn section explains the formats from the bytes up: how files are linked and loaded, and what the security features in them do. The Labs let you change bytes in a copy of a file and see what changes.

What it never does

It never runs a file you open, on the server or in your browser. It only reads the bytes. Analysis runs under time and size limits, so a malformed or hostile file is stopped rather than left running.

Where your file is processed

The same engine runs in three places: inside your browser tab (nothing is uploaded), on a hosted server (files are held in memory only), or on your own machine. The status bar of the tool says which one you are using. The privacy page has the details.
